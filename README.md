# ครูเอสคิว — เว็บนำเสนอโครงงาน (Three.js scroll story)

เว็บนำเสนอแบบเลื่อนหน้าจอ 14 ฉาก ครอบคลุมบทที่ 1–5 ภาคผนวก ก–ข และบรรณานุกรม
สร้างด้วย **Vite + React + TypeScript + React Three Fiber (three / drei) + Tailwind CSS**

## เริ่มใช้งาน

```bash
npm install
npm run dev      # http://localhost:5173
npm run build    # ตรวจ type + build ไปที่ dist/
npm run preview
```

Deploy บน Vercel: import โปรเจกต์นี้ (Framework = Vite) แยกจากโปรเจกต์ตัวแชทบอท

## วิธีใช้ตอนนำเสนอ

| การกระทำ | วิธี |
|---|---|
| เลื่อนไปฉากถัดไป/ก่อนหน้า | เลื่อนเมาส์ หรือปุ่มลูกศร ← → (ไล่หัวข้อย่อยในฉากก่อน แล้วค่อยไปฉากถัดไป) |
| ไปยังฉากโดยตรง | จุดเมนูด้านขวา, ปุ่ม ☰, หรือกด 1–9 / Home / End |
| โหมดนำเสนอ | ปุ่ม ▶ หรือกด **P** (ตัวอักษรใหญ่ขึ้น + จับเวลา ~1 นาที/ฉาก) |
| โหมดเบา | ปุ่ม ◐ หรือกด **L** (ลดอนุภาค/ความละเอียด — เปิดอัตโนมัติบนมือถือ/เครื่องอ่อน) |
| เต็มจอ | **F** |
| กระโดดเข้าฉากตรงๆ | เปิด URL ที่ลงท้ายด้วย `#results`, `#dataset` ฯลฯ |

## แก้ข้อความ/ตัวเลข

ทุกอย่างอยู่ใน [`src/content.ts`](src/content.ts) ไฟล์เดียว:

- `project.members` — ชื่อ–รหัสสมาชิก 6 คน
- `results` — ตัวเลขผลทดสอบ (รายคน, รายกลุ่ม, Confusion Matrix, ตัวชี้วัด)
- `questionTexts` — ข้อความคำถาม 110 ข้อ (ตามลำดับข้อ 1–110) สำหรับตารางภาคผนวก ข
- `chapterTitles`, `unitsPerChapter` — ชื่อบทและจำนวนหน่วยความรู้ต่อบท (ใช้วาดตาราง 172 ก้อน)
- `references` — บรรณานุกรมฉบับเต็ม
- ส่วนที่ติดป้าย **DRAFT** (เหตุผล 4 ข้อ, ข้อจำกัด 2 ข้อ, ขั้นตอน 8/7/5 ขั้น ฯลฯ) แผนระบุเพียงจำนวนข้อ — ให้แทนด้วยถ้อยคำจากเล่ม
